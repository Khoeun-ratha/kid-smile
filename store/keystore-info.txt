BUILD A RELEASE
---------------
In PowerShell, from D:\Mobile\kid_smile:

    .\store\build-release.ps1              # build current version
    .\store\build-release.ps1 -Bump        # raise version (1.0.0+1 -> 1.0.1+2) and build

The signed bundle is copied to your Desktop as kid-smile-<version>.aab.


RESTORE ON A NEW COMPUTER
-------------------------
1. git clone https://github.com/Khoeun-ratha/kid-smile.git
2. Copy your backup folder to D:\Mobile\kid_smile\release-keys (inside the project)
3. Copy mobile\android\key.properties.example to mobile\android\key.properties
   and fill in the password from key.properties.backup
   (or simply copy key.properties.backup over it).
   If the keystore is in a different folder, fix the storeFile line.
4. Run .\store\build-release.ps1


IF THE UPLOAD KEY IS LOST OR LEAKED
-----------------------------------
Because the app uses Play App Signing, the upload key can be replaced:
Play Console -> Test and release -> App integrity -> App signing ->
"Request upload key reset". Create a new key with:

    keytool -genkeypair -v -keystore upload-keystore.jks -storetype PKCS12 ^
      -keyalg RSA -keysize 2048 -validity 10000 -alias upload

then export its certificate and send it to Google as instructed there.
Google usually takes a few days to approve.
